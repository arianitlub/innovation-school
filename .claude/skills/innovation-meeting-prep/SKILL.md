# Other: Meeting Preparation Canvas – Feedback

Official RBI Innovation School prompt, stored word for word in `prompts/6.1.1-meeting-preparation-canvas.md`. Booklet principles: `docs/training/ai-prompt-library.md`.

## How to use

If the meeting is about the Innovation Challenge, use [`../EVIDENCE.md`](../EVIDENCE.md) for current context.

1. Read the prompt file.
2. Collect the seven canvas fields from the user (first impulse, underlying problem, goal, mode, people, invitation, constraints). Prefill from `docs/learning-transfer/`, `docs/training/learning-transfer.md` and `docs/working-context.md` when the meeting is the Learning Transfer workshop, and confirm with the user.
3. Answer as the prompt defines: a neutral sparring partner. Be direct, do not flatter.
4. Respect the hard limits: no agenda, timetable, sequence or run of show, no warm-ups or closings unless asked, under 600 words. Designing the meeting is the user's work.
