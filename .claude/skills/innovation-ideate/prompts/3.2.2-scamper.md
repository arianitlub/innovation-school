# PROMPT 3.2.2: SCAMPER Creative Technique Application

Use Case: Using SCAMPER method to generate breakthrough ideas

```text
I need to apply the SCAMPER creative technique to generate innovative ideas for [your challenge area].

Current situation/process: [DESCRIBE CURRENT STATE - e.g., "Customers currently need to upload 5 documents (ID, proof of address, income verification, company statements, employment letter) during account opening, which takes 15-20 minutes and has 40% abandonment rate"]

Apply SCAMPER systematically:

**S = SUBSTITUTE**
- What can we replace or substitute?
  * Technology: What if we substituted [X] with [Y]?
  * Process: What if we substituted manual steps with automation?
  * Channel: What if we substituted app with [something else]?
  * Data source: What if we substituted document uploads with [alternative data]?

Questions to explore:
- What if customers could use biometric data instead of documents?
- What if we used open industry APIs instead of requiring company statements?
- What if we substituted typing with voice commands?
- What if AI handled verification instead of human reviewers?

Generate 5-7 substitute ideas with descriptions

**C = COMBINE**
- What can we merge, combine, or integrate?
  * Features: Combine [X feature] with [Y feature]
  * Data: Combine information from multiple sources
  * Channels: Integrate mobile with [other channel]
  * Services: Bundle services together

Questions to explore:
- What if we combined step A with step B to streamline the process?
- What if one action also provided additional value?
- What if we combined our solution with complementary tools?
- What if we integrated third-party services or capabilities?

Generate 5-7 combination ideas

**A = ADAPT**
- What can we adapt from other contexts or industries?
  * From e-commerce: What lessons from Amazon/shopping apps?
  * From social media: What from Facebook/Instagram?
  * From gaming: What engagement mechanics?
  * From healthcare: What from patient portals?
  * From travel: What from Uber/Airbnb?

Questions to explore:
- How does Netflix personalize content - how could we adapt this?
- How does Amazon make processes frictionless - adapt for our context?
- How do various apps make onboarding engaging - adapt for our process?
- How do delivery apps provide status updates - adapt for our processes?

Generate 5-7 adapted ideas from other industries

**M = MODIFY, MAGNIFY, or MINIFY**
- What can we make bigger, smaller, faster, slower, more, less?

MAGNIFY:
- What if processing took 5 minutes instead of 5 days?
- What if we offered 24/7 support instead of business hours?
- What if we expanded capability significantly?
- What if onboarding took 30 seconds instead of 30 minutes?

MINIFY:
- What if we reduced required inputs from 5 to 1?
- What if required steps were 3 instead of 30?
- What if we simplified significantly?
- What if we focused on 5 core capabilities instead of 50?

MODIFY:
- What if we changed the order of steps?
- What if we changed when/where verification happens?
- What if we changed the interface paradigm?

Generate 5-7 modify/magnify/minify ideas

**P = PUT TO OTHER USES**
- How else could we use this process, technology, or asset?
  * Repurpose existing features for new uses
  * Use customer data for additional value
  * Leverage technology for different problems

Questions to explore:
- What if the technology/process also helped users with related tasks?
- What if one component also generated additional value?
- What if analytics also enabled proactive support?
- What if one tool could serve multiple purposes?

Generate 3-5 repurposing ideas

**E = ELIMINATE**
- What can we remove completely?
  * Steps in the process
  * Required information
  * Unnecessary features
  * Points of friction

Questions to explore:
- What if we eliminated authentication steps? (simpler auth)
- What if we eliminated manual data entry? (automation)
- What if we eliminated forms? (conversational interface instead)
- What if we eliminated waiting? (instant processing)
- What if we eliminated steps that cause friction?
- What if we eliminated complexity entirely?

Generate 5-7 elimination ideas

**R = REVERSE or REARRANGE**
- What if we reversed or rearranged the process?
  * Reverse roles: What if the company applied to the customer?
  * Reverse sequence: What if we started with [X] instead of [Y]?
  * Reverse assumptions: What if we did opposite of standard practice?

Questions to explore:
- What if the company pre-approved customers before they even applied?
- What if customers set requirements and companies competed for them?
- What if we onboarded customers before collecting documents? (trust first)
- What if we verified identity at the end instead of beginning?
- What if we handled problems BEFORE customers reported them?

Generate 5-7 reverse/rearrange ideas

SUMMARY & ANALYSIS:
1. Which SCAMPER dimension generated most interesting ideas?
2. Which ideas feel most feasible?
3. Which ideas are most radical/innovative?
4. Which ideas best address customer pain points?
5. Which ideas should we explore further?

OUTPUT FORMAT:
Ideas organized by SCAMPER dimension, each with:
- Idea name
- Description (2-4 sentences)
- How it addresses customer needs
- Innovation level (incremental/moderate/radical)
- Rough feasibility (easy/medium/hard)

Plus summary analysis and top 10 recommendations across all dimensions.
```
