# PROMPT 1.3.2: Data Analysis Framework & Methods

Use Case: Determining how to analyze the data you've collected

```text
I have collected data about our [your challenge area]. I need guidance on how to analyze it effectively.

My innovation challenge context:
[DESCRIBE YOUR CHALLENGE AND WHAT YOU'RE TRYING TO UNDERSTAND]

Data I have access to (or could potentially access):
[LIST WHAT DATA YOU HAVE OR COULD GET - e.g., "customer surveys, transaction logs, support tickets, operational metrics"]

Please provide an analysis framework:

1. TREND ANALYSIS OVER TIME
   - How to analyze key metrics' trends over time?
   - How to identify patterns, seasonality, or anomalies?
   - What statistical methods to use for trend analysis?
   - How to determine if changes are significant vs. normal variation?

2. SEGMENTATION ANALYSIS
   - How to segment the data to find patterns?
   - Suggest relevant segmentation dimensions based on my challenge (e.g., by customer type, product line, region, time period, user behavior)
   - How to identify which segments are most affected?
   - How to compare performance across segments?

3. FUNNEL / PROCESS FLOW ANALYSIS
   - How to map the end-to-end process or flow related to my challenge?
   - How to identify bottlenecks, drop-off points, or failure stages?
   - What metrics indicate problems? (completion rates, time duration, error rates, abandonment)
   - How to prioritize which issues to fix first?

4. ROOT CAUSE ANALYSIS
   - How to identify underlying causes vs. symptoms?
   - What analysis methods work well? (correlation analysis, regression, cohort analysis, before/after comparison)
   - How to test hypotheses about what's causing the problem?
   - How to avoid confusing correlation with causation?

5. PERFORMANCE & QUALITY ANALYSIS
   - How to measure performance or quality related to my challenge?
   - What leading and lagging indicators to track?
   - How to identify thresholds that matter (e.g., when does X metric impact Y outcome?)
   - How to correlate operational metrics with business outcomes?

6. COMPARATIVE & BENCHMARK ANALYSIS
   - How to compare our performance to industry benchmarks?
   - How to analyze competitive data or public information?
   - What internal comparisons are useful? (current vs. past, one team/region vs. another)

7. QUALITATIVE DATA ANALYSIS
   - How to analyze open-text feedback, comments, or survey responses?
   - How to categorize and theme qualitative data?
   - How to extract insights from interviews, complaints, or support tickets?
   - What tools or methods work well? (text analysis, sentiment scoring, theme clustering)

8. PRIORITIZATION FRAMEWORK
   - How to combine all analyses to prioritize actions?
   - Suggest a scoring model considering:
     * Impact on the challenge objective (high/medium/low)
     * Number of people/transactions/units affected
     * Cost or effort to address (easy/medium/hard)
     * Risk if not addressed

For each analysis type, provide:
- Step-by-step methodology
- What tools or Excel formulas to use
- What visualizations to create (charts, dashboards)
- What insights to look for
- Common pitfalls to avoid

OUTPUT FORMAT:
Structured analysis guide with methodologies, formulas, and visualization recommendations. Include an example analysis for one area.
```
