# PROMPT 2.3.1: Interview Data Analysis & Pattern Identification

Use Case: Finding patterns and themes across multiple interviews

```text
I conducted [NUMBER] empathy interviews about my innovation challenge: "[INSERT YOUR CHALLENGE]"

Now I need to analyze the data and identify patterns.

My interview notes include: [Paste what type of notes you will attach...]

Here are insights from my interviews:
[Paste or attach interview notes and transcripts...]

Please analyze this data and help me identify patterns:

1. PATTERN CLUSTERING - PAIN POINTS
   - Group similar pain points together into themes
      - Distinguish between:
     * Explicit needs (directly stated)
     * Implicit needs (inferred from behavior)
     * Latent needs (they don't realize they have)
   - Name each need cluster clearly
List all specific pain points under each cluster
   - Count how many participants mentioned each cluster

2. FREQUENCY ANALYSIS
   Create a frequency table:
   - Which pain points were mentioned most often?
   - Which needs came up repeatedly?
   - Which behaviors were common across participants?
   - Format: Theme | Count | % of Participants | Representative Quote

3. EMOTIONAL INTENSITY MAPPING (optional, if enough information on this is available!)
   - Which issues triggered strongest emotional responses?
   - What language indicates high frustration? (anger, giving up, switching companies)
   - What language indicates high anxiety? (worry, fear, mistrust)
   - What language indicates high satisfaction? (love, easy, prefer)
   - Score each theme by emotional intensity (1-10)

4. USER SEGMENTATION PATTERNS (optional, if enough information on this is available!)
   - Do different user groups have different needs/pains?
   - Analyze segments relevant to my challenge (suggest based on interview data):
     * By experience level
     * By proficiency or capability
     * By usage pattern (frequent vs. occasional)
     * By satisfaction level (satisfied vs. dissatisfied)
     * Other relevant segments
   - What's unique to each segment vs. universal across all?

5. BEHAVIORAL PATTERNS
   - Common workflows and workarounds
   - When and how users approach this area
   - What triggers frustration or failure
   - What drives satisfaction and success
   - Preferences and decision-making patterns

6. HYPOTHESIS VALIDATION SUMMARY
   For each hypothesis I tested, summarize:
   - Original hypothesis
   - Evidence across interviews (how many supported, contradicted, unclear)
   - Overall validation status (VALIDATED / PARTIALLY VALIDATED / CONTRADICTED / INSUFFICIENT DATA)
   - Key supporting quotes
   - Refinement needed (how to adjust hypothesis based on learning)

7. UNEXPECTED INSIGHTS & SURPRISES
   - What patterns emerged that I didn't expect?
   - What contradicts initial assumptions?
   - What did customers bring up that wasn't in my questions?
   - What "aha moments" stood out across interviews?

8. ROOT CAUSE ANALYSIS (optional, if enough information on this is available!)
   - For major pain points, what are the underlying root causes?
   - Use "5 Whys" thinking to go deeper
   - Example: "Why do users abandon step 3?"
     → "Because instructions are unclear"
     → "Why are instructions unclear?"
     → "Because we use jargon and don't show examples"

9. COMPETITIVE & COMPARATIVE INSIGHTS (optional, if enough information on this is available!)
    - What did participants say about competitors or alternatives?
    - What examples from other contexts did they reference?
    - What do they wish we would copy or adopt?
    - Where are we better/worse than alternatives?

10. KEY QUOTES BY THEME
    - Select the 5-7 most powerful quotes for each major theme
    - Choose quotes that are:
      * Emotionally impactful
      * Representative of common sentiment
      * Memorable and quotable
      * Useful for stakeholder presentations

11. CONFIDENCE & DATA QUALITY ASSESSMENT
    - Which patterns are strong (appeared in 70%+ of interviews)?
    - Which patterns are moderate (appeared in 40-70%)?
    - Which are weak signals (appeared in <40%)?
    - Where do we need more data?
    - Any contradictory data that needs reconciliation?

12. IMPLICATIONS FOR SOLUTION DESIGN
    - Based on patterns, what should our solution prioritize?
    - What are must-haves vs. nice-to-haves?
    - What trade-offs might we face?
    - What should we NOT do based on these insights?

OUTPUT FORMAT:
Comprehensive analysis report with:
- Clear theme names and descriptions
- Frequency counts and percentages
- Emotional intensity scores
- Representative quotes for each theme
- Segment-specific insights
- Hypothesis validation summary
- Priority recommendations

Maximum 2000 words with tables and bullet points for clarity.
```
