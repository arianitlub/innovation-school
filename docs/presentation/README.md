# Team Alignment Presentation

This folder contains the team-alignment presentation for the Mass-Affluent Wealth Advice Innovation Challenge.

Files generated by GitHub Actions:
- `innovation-challenge-team-alignment.pptx` - editable PowerPoint
- `innovation-challenge-team-alignment.pdf` - shareable PDF

The deck is intentionally framed as preparation for discussion, not as a final team decision or chosen solution. It separates documented evidence, reported observations, hypotheses, and candidate ideas, and follows the Innovation School Design Thinking flow.

Source file: `tools/create_innovation_deck.js`.
